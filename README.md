## Visual Worktree

可视化管理本地多个 Git 仓库的桌面应用，按「任务 / 需求」组织跨仓库 worktree（Electron · React · Git）。

- 任务化 worktree：一个需求跨多个仓库时，按任务聚合创建、查看和清理 worktree。
- 批量操作与状态总览：分支、未提交变更、领先/落后远程，批量拉取并显示逐项进度。
- 任务工作流与环境检查：记录流程步骤、状态和执行输出，检查依赖、端口与服务连通性。
- AI 配置：集中维护 Claude Code / Codex 全局指令、MCP 与 Skills。
- 本地优先，支持 macOS 与 Windows。

文档与下载：[Visual Worktree](https://imber-visual-docs.netlify.app/visual-worktree/)
